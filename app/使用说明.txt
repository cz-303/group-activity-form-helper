安装、卸载与清除数据（1.0 新增）
安装：运行“群活动填表助手-1.0-安装程序.exe”。默认安装到当前用户的 %LOCALAPPDATA%\Programs\群活动填表助手，不需要管理员权限；会创建开始菜单入口，可选桌面快捷方式，并在“设置 → 应用 → 已安装的应用”中显示。
数据位置：安装目录下的 data 文件夹（设置、任务数据库、备份、助手浏览器登录状态）。覆盖安装或升级只替换程序文件，不改动 data。
卸载：开始菜单“卸载 群活动填表助手”，或系统“已安装的应用”中卸载。卸载前请彻底退出助手。卸载窗口中“同时删除我的数据”默认不勾选；不勾选时 data 文件夹保留，重新安装到同一位置会继续使用。
清除全部数据：更多 → 清除全部数据并退出。经两次确认后，助手先安全退出（停止监测、关闭助手浏览器），再删除整个 data 文件夹，完成后弹窗提示结果。自动备份也在 data 中，会一并删除；需要保留时请先把备份复制到其他文件夹。删除本地数据不会撤回已提交到第三方平台的内容。

首次使用
解压整个文件夹，运行 群活动填表助手.exe。无需安装Python，需要本机Microsoft Edge。
首次请在设置中填写个人资料、目标群完整名称，并在“设置 → 群聊监测”中选择聊天客户端程序（必填）；新版本不内置任何真实个人资料。
聊天客户端保持展开并停留在设置中的目标群。如无法读取，请使用捕获诊断与自检。
左侧“监测 → 开始监测”；每轮读取当前可见消息，首次已显示的受支持文档链接也会保存。
新安装默认暂停任务处理。点击“处理 → 继续处理”后按自动跳转设置处理任务；关闭自动跳转的任务需手动打开。必须在填写前预览中确认后才填字，最终提交仍由你在网页操作。
暂停处理不影响已开启的群聊监测和提醒；停止监测不等于暂停任务处理。

补录 / 粘贴通知导入
入口：更多 -> 补录 / 粘贴通知导入。
粘贴完整正文，填写来源；一份通知中的多个文档链接关联同一原文。
多份不同通知用独立一行 --- 分隔，普通空行保留，不用来拆分通知。
若通知正文没有链接，可以填“补充链接”，此时一次只能关联一份通知。
点击“分析预览”查看识别到的链接、新增/合并数量，再“确认导入”。修改内容后必须重新分析。
不含支持链接的通知会在预览中说明，不会创建无链接任务；若需要，请单独补录并填写链接。
导入立即保存原文与任务。重复链接合并，不重置已处理、忽略或暂缓状态。
支持腾讯收集表 /form/page/、腾讯在线表格 /sheet/、金山文档 /l/ 的 HTTPS 文字分享链接。图片二维码只作为附件保存，不作为报名链接打开；小程序卡片请先在聊天客户端中打开并复制浏览器分享链接导入。

捕获诊断与自检
入口：监测 -> 捕获诊断与自检 -> 开始 / 重新检查。
显示聊天窗口数量、目标群识别情况、可读取消息数、识别链接数、已有/尚未保存数量。
检查是只读的，不自动切群、翻历史、发送消息或导入任务。
确认需要补录时，可点击“导入本次识别通知”，将这次读取的快照保存。
失败时给出群名、最小化、辅助模式、多窗口等检查建议。
成功只代表当次读取正常，不能保证历史消息或未加载内容已被捕获。

填写前预览（本版默认流程）
表单打开并登录、题目加载后，助手只读取题目和准备填写的资料，不立即填字。
选中任务，点击列表下方“填写前预览”，或使用任务操作菜单。
预览显示“表单题目 -> 准备填写内容 -> 状态”。选中可填写项可修改本次内容，清空表示跳过。
点击“确认填写（不提交）”才执行本次填写。不会自动点击网页提交。
修改只对本次预览有效，不更改全局个人资料，不将预览答案另存到任务数据库。
已有答案不覆盖；未匹配资料、重复题目、密码、验证码、附件、选择题等留在网页中人工处理。
需新增可匹配题目时，进入设置 -> 自定义资料，填写与表单一致的题目名称。
执行前再次核对网页地址、题目、字段状态及资料；发生变化会停止，并需重新预览确认。
一次确认只执行一次。已执行后，再次点击预览可请求重新检查剩余空白项，稍候再打开预览。
网页关闭、软件退出后预览失效；重启后如需继续，请重新打开该任务的表单并预览。
暂停处理、忽略或暂缓期间不执行已确认的填写；恢复后仍会先核对当前网页。
若执行中网页改变，已经填入的内容保留，后续停止，请人工核对。

活动备注、参加意向和准备清单
入口：任务操作 -> 备注 / 准备清单 / 专属提醒，或详情“处理信息”中的编辑按钮。
意向可选未决定、想参加、待考虑、不参加、已参加；只作记录，不自动改变任务或报名状态。
备注可记录地点、材料、安排等。准备清单支持添加、删除、勾选完成，双击可切换完成。
点击保存后持久保留；详情显示参加意向及准备完成数量，处理信息显示完整备注和清单。
备注和意向参与搜索；导出CSV包含备注、意向、清单和提醒方式。
清单完成、标记已参加不等于网页已提交，软件不猜测报名成功状态。

任务专属提醒
活动管理 -> 专属提醒：沿用全局、自定义、关闭本任务提醒。
自定义提前量如 60,30,10 表示截止前1小时、30分钟、10分钟，替代全局截止提醒设置。
需先保存有效截止时间；自定义模式即使全局截止提醒关闭仍生效。
已处理、忽略、暂缓任务不触发截止提醒。相同截止时间、相同提前量只提醒一次。
“保存并在10分钟后再提醒”是额外的一次任务提醒，不需要截止时间，不会暂停任务处理。
关闭本任务提醒会取消其待执行的再次提醒；该开关针对截止和再次提醒，不关闭原通知更新提示。
再次提醒到时若任务忽略/暂缓，会保留至恢复进行中；已处理不会再提醒。

活动时间与全局提醒
任务操作 -> 编辑活动时间 / 截止时间，或详情“活动时间”页签。
格式为 YYYY-MM-DD HH:MM 或 YYYY-MM-DD；只填截止日期按当天结束计算，留空可清除。
日期由你核对保存，通知时间文字仅供参考，不自动猜测缺少的年份或相对日期。
倒计时读取电脑当地时间；提醒约每5秒检查一次。时钟或时区变更会影响计算。
设置 -> 提醒：默认提前60和30分钟；可设置最多10个提前量，每个1—10080分钟。
离线期间跨过多个提前量，重新运行且尚未截止时只补一条；过期不补发。
软件关闭、休眠期间不会提醒。提醒不会自动报名、提交或丢弃任务。

重复通知、更新提示与提醒中心
同一规范化收集表链接只保留一个任务，查询参数和末尾斜杠不生成重复任务。
相同来源和正文去重；不同正文保留在该任务下。同一正文转发不会触发更新提醒。
发现新版本正文会标记[更新]，可查看最近两份不同正文的文字变化；“标记更新已读”清除任务标记。
捕获顺序不等于发布时间，旧通知重发也可能显示变化，需核对原文。
新通知不会覆盖已确认的活动时间。不同链接不会仅凭相似内容合并，以免误合并报名表。
提醒中心保存监测异常/恢复、通知更新、截止、再次提醒和备份失败记录，最近300条可浏览。
浮窗与提示音在设置中控制；默认不播放声音。提醒浮窗消失后记录仍可查看。

监测异常提醒
默认连续异常30秒后提示，可设10—600秒。同一段异常只提醒一次，恢复成功读取后提示恢复。
监测响应等待阈值至少为两个检查间隔加5秒，避免长检查间隔误报。
主动停止监测不报警。若聊天客户端未提供辅助功能文字、已最小化、切群或未加载消息，可能无法捕获。
程序不读取客户端进程内存，不遍历未打开的群，不发送群消息。

升级与数据迁移
入口：更多 -> 升级与数据迁移。
1. 导出当前数据为迁移包：选择保存位置，包含任务、通知、备注、清单、提醒和个人设置。
2. 导入迁移包 / 备份包：校验后显示信息，由你确认，下次启动生效。
3. 直接读取旧版文件夹：选择旧版程序目录或data目录，读取数据库快照并仅升级副本，不更改旧版文件。
请先退出旧版助手。迁移是替换当前任务和设置，不是合并；恢复前保留安全副本。
安排迁移后，请处理未提交网页，彻底退出助手并重新启动；恢复后处理暂停，监测未启动。
浏览器登录状态不在迁移包中，新版可能需重新登录腾讯文档。
本功能处理数据迁移，不自动下载、安装或替换程序。
仍可在首次运行新版前备份并复制旧版data文件夹到新版旁；不要覆盖已经产生新任务的新版data。

备份、外观与关闭方式
设置 -> 外观与备份：默认每24小时自动备份，保留10份，可设置间隔与保留数量，也可立即备份。
自动备份只在程序运行时检查，手动备份和恢复前副本不会自动清理。备份位于data/backups。
备份/迁移包含个人资料，不包含浏览器登录状态；请妥善保管。恢复包会校验完整性和数据库结构。
浅色/深色主题保存后立即生效，主界面、设置及新窗口随之切换。
关闭按钮可选最小化到托盘、彻底退出或取消；双击右下角托盘图标恢复。
最小化的是助手，聊天客户端仍需展开并停留在目标群；新图标也用于EXE、窗口和托盘。
若Windows仍显示旧快捷方式图标，可删除旧的固定快捷方式，再固定新版EXE；无需清理系统图标缓存。
彻底退出会停止工作并关闭助手浏览器，请先处理未提交内容。

数据与验证
程序旁data/config.json保存个人资料/设置；tasks.sqlite3保存任务及活动管理数据；browser保存专用浏览器登录状态。
测试和演示任务不随程序分发；软件不发送诊断结果、通知或个人资料到外部服务。
通过80项功能与回归测试，包含审批前不填字、一次审批只执行一次、网页变化停止填写、补录关联、旧目录不被修改和专属提醒。
完成新窗口布局检查；打包程序另行验证托盘、图标、表单解析、备份恢复等。
真实聊天客户端新通知到真实报名提交的完整流程仍需实际使用验证；本程序始终由你手动提交。

源代码随包提供，Python源码运行依赖见requirements.txt；EXE用户无需安装这些依赖。

隐私与数据保管
姓名、学号、自定义资料、任务和备份仍以本地明文保存，不应把data目录发送给他人。
软件不带遥测、不上传诊断记录；开启表单后由腾讯文档处理网页交互，填写信息可能在提交前就被网页脚本读取。
浏览器登录状态位于data/browser，不包含在助手备份中。
日志不写异常原始消息、资料内容、完整本地路径，保留最多3份约500KB诊断文件。
永久删除本地记录前请彻底退出并备份需要保留的内容，然后自行删除data及外部导出的备份/迁移包/CSV。
删除本地数据不会撤回已经提交到平台的数据，也不承诺磁盘取证级不可恢复。

升级方式
先彻底退出旧版，在新版“更多 → 升级与数据迁移 → 直接读取旧版文件夹”选择旧版目录。
确认安排迁移后，彻底退出并重新启动新版；核对资料和任务，再继续处理。旧版目录不改动。
也可导入旧版备份包；迁移是替换，不是合并，不迁移浏览器登录状态。

当前支持范围
实际监测/填写仍为群聊可访问文字消息与腾讯收集表。微信、问卷星未接入执行。
普通网址和自定义Scheme仅为核心识别能力，不会自动调用本地程序。
新增平台真正接入并验证后，软件将统一更名为“活动填表助手”；当前不表示微信或问卷星已可用。

空行候选预览（v0.20）
复制表头和下面若干数据行的矩形范围，点击粘贴范围分析；或使用实验性网页读取。选择并核对表头行，点击“确认表头并检查空行”。
仅根据本次范围快照判断：任何非空文字（包括空格、0、公式文字及其他读取列内容）均视为已有内容。跳过中间空洞，从所读范围内最后一条已有数据之后寻找候选。
若 A2 有 234，A2 所在行不会当成空白；所读范围包含第3行且为空时，可显示第3行候选。
只有表头、末行已有内容、重复字段、表头中间空白、多个候选表头等情况会停止或要求扩大/缩小范围，不猜测范围之外的内容。
粘贴各行列数不一致时拒绝分析；不得把缺失数据补成空白。请复制完整矩形范围，空白行也需保留对应列的制表符。
结果明确显示候选坐标，仅代表读取范围内文字为空，不验证范围外列、隐藏/筛选/合并/保护或显示为空的公式；不会写入，不代表可安全填写。在线表格仍需在网页人工操作。
修改或重读数据、改变表头选择会清除旧候选；新快照须重新确认。
同时只打开一个表头窗口；选择另一任务时会提示先关闭原窗口，避免混淆预览来源。

腾讯在线表格确认写入（v0.21 测试版）
选中任务 → 表头读取预览 → 读取/粘贴包含表头和数据的范围 → 核对表头行 → 确认表头并检查空行 → 填写预览。
填写预览显示文档、工作表、目标行、列名和本次内容。选中已匹配列可修改本次内容；空白跳过，未知字段需在设置添加自定义资料后重读，不自动覆盖。
必须在助手自己启动的 Edge 中打开并登录该表格，且继续任务处理；其他浏览器的登录状态不与助手共享。粘贴只能提供参考预览，不开放确认写入；自动写入必须先通过网页读取绑定真实工作表，执行时再重新读取并核对。

确认只使用一次，新快照、失败或重新打开必须重新读取、预览和确认。不自动重试，也不清除、回滚已写入内容；失败后在网页核对部分内容是否已经保存。
公式前缀、超过15位数字或带前导零的纯数字暂不自动填写，避免公式执行、格式或精度丢失；每格最多4000字，不支持换行/制表符/空字符。日期、小数和其他表格自动转换规则未全部验证，必要时在网页手动填写。
填写成功只表示指定单元格已回读核验，不代表报名成功或已提交，不自动标记任务完成。
本次真实页面验证覆盖动态表头定位、单个空白单元格写入并回读；整个助手的多字段写入、长时间挂机和复杂表格尚未完成真实端到端验收。旧版“不写入”描述对应旧阶段，本版仅在填写预览确认后启用腾讯简单表格写入。金山自动填写尚未启用。

监测/处理状态区各有直接控制按钮，原菜单仍可使用。多选时仅显示批量操作说明，单项编辑和预览不可用。空清单可导入通知/设置目标群，筛选无结果可直接重置。
