# 界面与状态规范 · 1.1

本轮复用 Tk/ttk、Pillow 和现有后台任务机制，没有替换界面框架、增加依赖或修改数据库格式。

## 字体、布局与形状

- 字体统一 Microsoft YaHei UI；正文 10pt、辅助说明 9pt、分区标题 12pt、页面标题 16pt。由 `design_tokens.FONTS` 维护；Tk 根据 DPI 缩放点数。
- 主窗口采用侧栏导航、独立内容区；浅色使用浅灰侧栏、白色内容，深色使用中性灰。主按钮使用高对比中性色，反馈仍使用原有语义色。
- 侧栏导航使用轻量按钮，保留键盘焦点和禁用行为；详细操作通过原有分组菜单访问。
- 标题栏保持 Windows 原生样式和行为，不覆盖系统强调色。署名 “Designed by Chen Zhuo” 仅在主界面右下角呈现。
- 常用间距采用 4、8、12、16、24；页面和对话框主要内边距为 16，控件横向间隔通常为 8。
- 按钮、输入框、下拉框、菜单按钮、监测与处理分区使用 8 逻辑像素圆角。九宫格图片边框保留 ttk 的焦点、键盘、只读、禁用及命令行为。
- 主要按钮用于当前页面的确认操作；“设置”等导航使用次级样式；不可逆清理采用 `Danger.TButton`，且保留预览和二次确认。
- 窗口外框、系统消息框、表格及菜单等仍采用原生结构，避免自绘控件损害操作习惯。
- 启动时启用系统 DPI 感知，窗口初始尺寸按比例计算并限制在屏幕可用范围内。运行期间跨不同 DPI 显示器的热切换不在本轮保证范围，必要时移动后重新启动。

## 统一操作状态

| 状态代码 | 显示前缀 | 用途 |
|---|---|---|
| idle | 就绪 | 等待用户开始 |
| empty | 暂无内容 | 没有匹配或可处理内容 |
| info | 提示 | 中性说明、人工标记结果 |
| running | 进行中 | 正在读取、查询、备份或等待后台操作 |
| success | 已完成 | 已核实完成的当前操作，如保存、导入 |
| warning | 需留意 | 待确认、暂停、部分完成、人工补填 |
| error | 未完成 | 操作失败，保留内容并给出重试入口或方法 |
| cancelled | 已取消 | 用户取消当前操作 |

`StatusVar` 保存原文和独立状态，`StatusLabel` 呈现中文前缀与语义色。不得根据通知正文中的“成功”“失败”等词猜测状态。工作线程通过 `App.emit(text, state=...)` 发事件，由 UI 线程更新控件；不得在工作线程直接修改 Tk 变量。

浅色、深色分别提供信息、成功、警告、错误和中性前景/背景色。所有状态配文字，不能只靠颜色。正文语义色及主要按钮文字与背景对比度自动检查不低于 4.5:1。禁用和键盘焦点属于控件状态，不写入任务数据。

任务的待处理、打开中、已打开、打开失败、暂缓、忽略、已处理仍保留原有业务含义。网页打开、预览批准、用户标记已处理均不等于报名提交成功。程序不会自动提交表单。

## 操作反馈约定

- 监测和任务处理状态独立显示；查询、文件及后台检查只在需要时展示附加反馈。
- 表单编辑错误使用原生错误框；输入内容保留。关闭窗口后仍可从主窗口查看操作结果。
- 通知导入：没有当前预览时确认按钮禁用；正文、链接或来源改变后立即失效；解析失败不能沿用旧授权。
- 捕获诊断：检查中禁用重复检查和导入；无链接、失败、成功分别提示；成功导入后避免重复点击。
- 数据清理：空选项、空结果、预览待确认、执行、完成、部分失败和取消使用统一状态；失败不把任务标为完成。
- 状态控件销毁时解除变量监听，避免晚到的后台结果调用已销毁控件。

## 后续扩展

新界面复用本文件规范和现有控件。不要新增一套调色板或直接写颜色常量；优先为缺失语义补充共享 token。平台适配器及核心业务不得依赖这些 Tk 样式模块。

设置标签页首次选择时创建一次，切换保留编辑内容。新窗口只遍历自身控件；主题切换才刷新整棵窗口树。尺寸与滚动区事件合并至 idle 回调，并在销毁时取消。

持续缩放使用40ms定时合并，保留最新事件；相同文字换行宽度不重复配置。筛选栏横排阈值使用±16逻辑像素缓冲。

监测/处理状态区各有直接控制按钮，原菜单仍可使用。多选时仅显示批量操作说明，单项编辑和预览不可用。空清单可导入通知/设置目标群，筛选无结果可直接重置。

任务处理设置：自动跳转与启动恢复直接可见；并发/重试参数在“高级选项”展开编辑；详细打开与重试规则按需展开。折叠不会重置输入，取消不会保存。

窄窗口：选择任务后点击“查看详情”、双击任务或按Enter进入详情，点击“返回列表”回到任务清单（通知文本可按Esc返回）。多选仍可批量操作。打开、任务操作与预览按钮位于共享操作栏，两种视图均可用。内容区低于840逻辑像素采用单栏，边界使用±24逻辑像素缓冲；持续尺寸更新沿用40ms合并。

详情头部：标题与元信息仅显示单行摘要，按实际字体和宽度省略；完整原文不截断。详情读取完成后可在操作栏点击“完整信息”查看可复制、可滚动的只读快照。较矮的详情区隐藏元信息摘要，扩大正文区域；增高后恢复，完整信息入口保持可用。缩放和文字变更沿用40ms合并更新。
